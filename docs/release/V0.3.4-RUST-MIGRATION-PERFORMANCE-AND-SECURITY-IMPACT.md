## 2. Security & Reliability Impact

1. **GIL-Free Native OS BLE Calls:** `probe_native_ble_adapter_raw` and `NativeBleTransportManager` operations execute inside `py.allow_threads(...)`, preventing Textual UI stalls during Bluetooth adapter/radio queries or GATT operations.
2. **Fail-Closed Noise XX Preserved Against `bitchat-tui` Anti-Patterns:**
   - Rejects nonce-0 replay (unlike `bitchat-tui`'s `if n > 0` bypass).
   - Rejects tampered handshake payloads without swallowing AEAD failures.
   - Never writes private keys, shared secrets, nonces, or plaintext messages to logs or diagnostic traces.
3. **Strict Peer-ID & GATT Hygiene:**
   - Rejects truncated (<8 byte), all-zero (`0000000000000000`), and broadcast (`ffffffffffffffff`) BLE service-data peer IDs.
   - Rejects GATT characteristics lacking required `notify` or `write`/`write-without-response` capabilities.
4. **Decoupled Windows Peripheral Fault Isolation:**
   - Companion manufacturer advertisement failures no longer destroy a live `GattServiceProvider` or `GattLocalCharacteristic`.
